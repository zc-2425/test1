> 依据：`_ref/_spec/B1–B8` 共 8 份页面规格 JSON（62 画布 / 33 路由）+ `docs/01-页面清单.md` + `docs/02-信息架构.md`。

## 1. 骨架类

### 1.1 `AppShell`

| 项 | 内容 |
|---|---|
| 出现页数 | 51 / 62 |
| 用于页面 | 除 `/login`（全屏无壳）与 `/workflow/:id/canvas`（无侧栏）之外全部 |
| 布局 | `AppTopbar`(fixed 56) + 横向：`AppSidebar`(202) + `<main>`(滚动) |

```ts
interface AppShellProps {
  /** 隐藏侧栏（画布页） */
  hideSidebar?: boolean
  /** 内容区最大宽度，默认 1400；弹窗背景页传 'full' */
  maxWidth?: number | 'full'
  /** 内容区上下内边距，默认 24 */
  padding?: number

```

备注：`/workflow/:id/canvas` 不用 `AppShell` 的侧栏，但仍保留顶栏（截图顶栏存在，只是被遮罩压暗），故实现为 `<AppShell hideSidebar>` 复用顶栏；`/login` 走独立 `AuthLayout`。

### 1.2 `AppSidebar`

| 项 | 内容 |
|---|---|
| 出现页数 | 51 / 62 |
| 用于页面 | 全部后台页 |
| 实测 | 宽 202px；右缘 1px `#DBD8DC`；底 `#FEF7FF`；激活 **整行**实底 `#6750A4` + 白字白图标；未激活文字 `#43525A` 级；图标 20px 线性 |

```ts
interface SidebarItem {
  key: string            // 'explore' | 'workflow' | ...
  label: string          // 探索 / 工作流 / 应用中心 ...
  icon: string           // Material Symbols 名
  to: string             // 路由
  matchPrefix?: string[] // 高亮前缀，默认 [to]
}
interface AppSidebarProps {
  items: SidebarItem[]        // 固定 11 项，顺序见 02 文档
  activeKey?: string          // 由路由计算，不靠菜单文案
  collapsed?: boolean         // 原型无折叠，默认 false
}
```

备注：① 11 项**平铺**，无分组标题、无二级、无折叠柄、无底部版本号。② **高亮必须按路由判定**（原型有两处高亮错位：`11-工具-创建`、`11-工具-文本摘要器` 高亮在「数据集」）。③ 激活态是**直角整行填充**，不是 M3 的 28px 药丸 indicator，见 04 文档 M3 判定。

### 2.1 `AppDataTable`

| 项 | 内容 |
|---|---|
| 出现页数 | 20 / 62 |
| 用于页面 | `/workflow/list`、`/app/list`、`/knowledge/list`、`/agent/list`、`/prompt/list`、`/tool/list`、`/dataset/list`、`/llmops/models`、`/llmops/ab-test`、详情页内嵌表 |

```ts
interface ColumnDef<T> {
  key: keyof T | string
  title: string
  width?: number | string
  align?: 'left' | 'center' | 'right'
  /** 单元格渲染器：两行主副文 / 徽章 / 进度 / 图标+数 / 可点击紫字 */
  cell?: 'text' | 'two-line' | 'badge' | 'progress' | 'icon-number' | 'link' | 'chips' | 'custom'
  sortable?: boolean
  ellipsis?: boolean
}
interface AppDataTableProps<T> {
  columns: ColumnDef<T>[]
  rows: T[]
  rowKey: keyof T | ((r: T) => string)
  /** 行内操作：▶ 运行 / ⋮ 更多 / 刷新 / 下载 */
  rowActions?: Array<{ key: string; icon: string; label: string; danger?: boolean; show?: (r: T) => boolean }>
  selectable?: boolean          // 原型未画，建议补
  loading?: boolean
  empty?: EmptyStateProps
  /** 分页：原型 62 页**全都没有分页器**，实现必须补 */
  pagination?: { page: number; pageSize: number; total: number }
  onRowClick?: (r: T) => void
  onRowAction?: (key: string, r: T) => void
}
```

备注：① 原型无一张表有分页/搜索/状态筛选，实现必须补齐（7 个列表页 + 2 个 LLMOps 表）。② 已知三处表头/列值错位：`03-工作流管理`（类型/状态/节点数/时间顺序错）、`10-数据集管理`（「最后更新」列实际渲染进度条，缺「进度」列头）、`04-应用管理`（操作列有列头但单元格为空）——按语义重建，不照抄。③ 行内操作固定两个图标（▶ + ⋮），文本为零，需要 `title`/`aria-label`。
